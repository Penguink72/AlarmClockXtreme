# 現行需求｜個人音樂鬧鐘 MVP（2026-11-11）

**狀態：T0 規劃／未實作。這是目前唯一的需求優先依據。** 若舊 G1／B0 文件有衝突，以使用者最新要求和本頁為準。

## 使用者要的 App

保留原版定時鬧鐘。使用者一次授權後，**不必逐首勾選**，將手機和 microSD 可存取的音樂整批建立為同一個**至少 3,000 首**音樂庫；鬧鐘每首自然播完**重新獨立隨機抽取**下一首（相鄰重複完全可以）；真正開始播放時顯示歌名、追加日期／時間／順序／歌名；解除後能按日期查看。

## 當前必做 MUST

| ID | 必須能做到 | 限制與驗收 |
|---|---|---|
| R-01 | 設定定時／重複鬧鐘、解除及貪睡 | 沿用原版 AlarmScheduler、通知、音量等，不重寫整套鬧鐘 |
| R-02 | 整批匯入音樂，不逐首勾選 | MediaStore 查詢**已授權且受索引的**手機＋microSD 音訊；沒被系統索引者，提供指定資料夾 SAF 授權並**遞迴子資料夾**補掃 |
| R-03 | 同一音樂庫至少容納 3,000 首 | 保存 URI、歌名／檔名、來源，去重、顯示實際索引數；不可使用舊 20 首 ringtonePool 欄位裝新庫；不複製 MP3 |
| R-04 | 每首播完再抽一次 | 從當前有效候選以 random.nextInt(N) 獨立隨機選；允許 A→A；**不用**預洗牌、避免重複、輪完再重播 |
| R-05 | 響鈴畫面顯示目前播放曲名 | 取**實際播放**的歌曲；沒有音訊標題時顯示檔名 |
| R-06 | 關鬧鐘後可按日期、時間、順序查看播放記錄 | 每首**確實開始播放**只新增一筆 startedAt／playOrder／titleOrFilename／必要的 URI；同首重新播放另記新筆 |
| R-07 | 簡易歷史即可 | 不記錄 completed/interrupted/failed、結束時間、長度、統計；不在結束時回寫；暫停／恢復不得重複記 |
| R-08 | 歷史在關鬧鐘和重開 App 後可讀 | App 私有本機資料即可；**不要求跨卸載重裝、歷史格式升級或備份保證**，也不刻意在正常更新時刪除 |
| R-09 | 可靠響鈴、停止與失效音源備援 | 解鈴／貪睡／搶占／超時後不得再抽歌；壞 URI 有界跳過後改用預設鈴聲；寫日誌失敗不妨礙鬧鈴 |
| R-10 | GitHub 產 APK 並可安裝 | G0 嚴格依賴驗證下真正編譯，附 APK artifact／日誌；白天手機實測 |
| R-11 | 原版鬧鐘未啟用新模式時行為不變 | 保留原單曲、舊 20 首 pool 與播完解除，確保原有鬧鐘設定不遺失 |

## 實作限制

- 首版必驗 MP3、WAV；其他音訊格式視裝置解碼器支援。MP4 等影片容器不是首版保證項目。
- MediaStore 無法無授權讀取所有路徑；SAF 也可能不能選整張 SD 根目錄。顯示「實際找到數」，不能宣稱未找到的檔案不存在；授權一次資料夾即可補掃，**不用逐首挑**。
- 背景建立與刷新音樂索引，可取消；響鈴時只讀已儲存候選，不掃描 3,000 首、不把 3,000 個音訊物件載入記憶體或 APK。
- 歷史可使用 App 私有 append-only JSONL 或實作者核對後同等簡單的方式；**不因日誌需求引入完整事件狀態機**。
- 新模式預設不啟用，若真的更動 Alarm Room entity 才要對該設定做 migration；「播放歷史可失去」不代表可丟失原有鬧鐘時間／設定。
- 判斷已播必須有 isPlaying 或等效證據；單純被選中／播放器 READY 不足以寫播放紀錄。

## 最小實機情境

手機和 microSD 合計 3,000 首以上、跨多個音樂資料夾；授權後一鍵掃描並顯示 N≥3,000，必要時授權指定資料夾遞迴補掃。白天測試鬧鐘連續抽歌，A→A 也算正確。每次真播顯示曲名並記一筆；解除後依日期／順序能查看；記憶卡移除時仍有備援鈴聲。

## 不是本階段需求

舊 20 首逐首勾選／貼入 URI 方案、Media3 整份 playlist shuffle＋repeat-all、每日輪換、避免重複／shuffle bag、加權隨機、完整播放完成／中斷／失敗紀錄、歷史跨版本／重裝保證、統計報表、外部串流／影片音訊保證，均見 [DEFERRED-DESIGNS.md](DEFERRED-DESIGNS.md)。**未來使用者有實際需要並重新明確要求才恢復；不主動排程。**

原始碼事實：RingtoneFolderStore 現只列已選資料夾直接子檔案；Alarm.ringtonePool 最多 20 首；AlarmService 目前每場隨機選一首。這些並不表示新功能已完成。
